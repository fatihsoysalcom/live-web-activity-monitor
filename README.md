# Live Web Activity Monitor

This example demonstrates a "dependency-free live monitoring" concept for web applications, inspired by the "Chrome Live" idea. It showcases how client-side JavaScript can track user interactions (clicks, mouse movements, key presses) and display application metrics (like an uptime counter) in real-time directly on the web page. This approach helps developers observe live behavior and potential performance issues without external tools.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in your web browser.
3. Interact with the page (click, move mouse, type keys) to see the live event log and metrics update.
